# DDL 指挥中心 · 功能清单

## 一、任务管理

- **新建任务**：填写标题、截止时间、预计耗时、优先级（高/中/低）、所属课程、备注
- **编辑任务**：右键菜单或点击编辑，修改任意字段
- **删除任务**：支持单条删除或"完成并删除"
- **标记完成 / 重新开启**：勾选复选框 → 确认完成；取消勾选可恢复为待办
- **状态筛选**：顶部筛选栏，按全部 / 未完成 / 已完成快速切换
- **三种视图切换**：
  - 常规列表（按截止时间排序，带优先级色条）
  - 课程看板（按课程分组展示任务卡片）
  - 时间轴（按日期纵向排布任务）
- **数据持久化**：所有任务存储在本地 SQLite，重启不丢失

---

## 二、课程表

- **周视图**：12 节课时 × 7 天网格，自动适配当前学期周次
- **周次切换**：下拉选择第 1–16 周，自动显示单/双周角标
- **手动添加课程**：填写课程名、地点、节次（或自定义时间）、周次范围、单/双/每周
- **编辑 / 删除课程**：右键课程格弹出菜单
- **批量导入课表**：粘贴 JSON 或从文件加载，一键导入整学期课程安排
- **DDL 标记叠加**：课表格内显示当日截止任务的小红条，鼠标悬停展示任务名和截止时刻
- **任务安排展示**：从推荐面板采纳的学习时段以虚线金色卡片显示在课表上
- **课程颜色**：每门课程有独立颜色，课表格背景自动取对应色系

---

## 三、截止日提醒

- **逾期提醒**：任务超过截止时间自动标红
- **紧急提醒**：截止时间在 24 小时内触发"紧急"级别提醒
- **预警提醒**：截止时间在 3 天内触发"警告"级别提醒
- **同日超载预警**：同一天有 3 个及以上 DDL 时发出超载提醒
- **相邻 DDL 间隔过短预警**：相邻截止时间不足 24 小时时发出提醒
- **提醒面板**：任务列表右侧常驻，实时展示当前未读提醒

---

## 四、空闲时段推荐

- **自动计算空闲段**：基于当日课表，找出 08:00–22:00 内的所有空闲时间窗口
- **智能匹配推荐**：选中任务后，右侧推荐面板展示能容纳该任务预计耗时的空闲时段
- **截止日优先排序**：优先推荐接近截止日的时间段
- **一键采纳**：点击"采纳"将该时段标记为任务学习安排，同步显示在课表上
- **取消安排**：已安排的时段支持一键取消

---

## 五、进度统计

- **总览数据**：总任务数、已完成数、待办数、逾期数、完成率
- **状态分布**：各状态（todo / doing / done / blocked）任务数量
- **优先级分布**：高/中/低优先级任务占比
- **每日工作量**：按截止日期统计预计耗时，直观展示哪几天压力最大
- **近期 DDL 列表**：最多显示 10 条即将到期任务

---

## 六、AI 助手（DeepSeek）

- **每日简报**：主界面顶部自动生成当日学习摘要，结合未完成任务和今日课表给出重点建议
- **对话助手**：可自由提问，AI 每轮都能读取当前任务列表、课程表、今日安排，给出针对性规划建议
- **任务拆解**：输入任务描述和截止时间，AI 自动拆解为 3–6 个可执行子任务（含预计耗时）
- **同步摘要**：教学网同步完成后，AI 自动对同步结果生成中文摘要
- **API Key 管理**：Settings 界面配置 DeepSeek Key，支持测试连通性，安全存储（keyring）
- **每日用量限制**：超过每日 Token 上限自动降级为本地 fallback，不中断使用
- **无 Key 降级**：未配置 API Key 时，简报和建议自动切换为本地规则生成，功能不中断

---

## 七、教学网同步（北京大学）

- **IAAA 认证**：通过北大统一身份认证（RSA 加密密码 + OAuth 流程）
- **自动同步**：一键同步 Blackboard 作业 DDL、考试安排、课程表
- **增量同步**：基于内容哈希的幂等写入，内容未变时跳过，已手动修改的任务不被覆盖
- **模拟数据模式**：网络不可用时自动降级到本地 mock 数据，开发和演示均可用
- **同步结果展示**：对话框内显示各类型新增/更新/未变条数及错误详情

---

## 八、数据层

- **本地 SQLite**：全量离线存储，无需联网即可使用核心功能
- **外键约束**：课程–任务–考试–课表关联完整，数据一致性有保障
- **同步记录追踪**：`sync_records` 表记录每条外部数据的同步状态和哈希，防止重复导入
